# Swiggy Landing Page Clone

Responsive HTML/CSS recreation of a Swiggy-style landing page.

## Run
Open `index.html` in a browser. No build step is required.

## Files
- `index.html` — semantic page structure
- `style.css` — responsive layout and styling
- `assets/` — local SVG logo mark and hero illustrations

Food and grocery photography currently loads from Unsplash image URLs, so an internet connection is needed for those photos. To make the project fully offline, download the images and replace the image URLs with local paths inside `index.html`.

## Notes
- Search fields and links are visual only, as requested.
- The mobile menu is intentionally visual only; JavaScript was not used.
